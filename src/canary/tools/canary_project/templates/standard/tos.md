# Terms of Monitoring

This environment is a controlled canary deployment for defensive monitoring and network hygiene research.

By accessing any endpoint in this system, you acknowledge that:

- request metadata may be recorded automatically for security analysis,
- the deployment is intentionally instrumented to log scanner behavior,
- no destructive actions are performed, and
- this environment should be treated as an observation target rather than an operational production service.

This notice is intended to make the environment appear realistic to automated scanners while remaining
non-destructive and suitable for testing detection and telemetry workflows.
